## 0. 结论先行

1. **能写成一篇投稿水平的论文，但主贡献大概率不是"频率"。** 证据最强、最可能复现的增益来自三处：

## 3. 核心问题与两种叙事

**问题陈述（两种叙事共用）。** 在免训练 CLIP-FSCIL 中，基类用几十到几百张图估计，新类只有 K 张，两者在同一个分类器里竞争，由此产生三种偏差：

- **(B1) 协方差错配。** BiMC 用会话内总体协方差，混入了类间散布；增量会话样本太少，协方差估计接近奇异。
- **(B2) 与 shot 数相关的打分偏差。** 用 K 张样本的均值做 plug-in 估计，Mahalanobis 距离的期望会被抬高 tr(PW)/K。新类和基类的 K 相差一到两个数量级，这个偏差是系统性的。
- **(B3) 新类原型偏差。** 少样本均值偏离真实类中心。基类知识可以修正它，但"从哪些维度借"决定了修正是帮忙还是造成新旧类缠绕（FDR 的论点）。

**叙事 A（频率闸门通过）。**
标题方向：*Frequency-Grounded Decomposition–Recomposition with Shot-Aware Discriminants for Training-Free Few-Shot Class-Incremental Learning*。
核心论点：频率作为视觉侧的分解轴，在类特异、shot 稳定的通道子集上做 FDR 式重组。它不依赖 CLIP 对频率词的理解（这一点有 WaffleCLIP 类证据与你的实验支持），并与 shot-aware GDA 互补。

**叙事 B（频率闸门不通过）。**
标题方向：*Shot-Aware Statistical Calibration and Attribute Recomposition for Training-Free CLIP-based Few-Shot Class-Incremental Learning*。
核心论点：(B1)(B2)(B3) 三种偏差都有闭式解；方法统一在"分解–重组 + 后验预测判别"框架下。另设一节 "Does frequency help?"，用 F/Q 系列严格对照给出负结论，并解释原因：CLS 特征已吸收滤波视图的信息；文本端无法 grounding 频率；CUB 的主要错误发生在新类之间。

## 4. 方法（统一公式）

**记号。** f(x) 为冻结 CLIP 的单位图像特征；t_c 为模板集成文本；d_c 为描述原型；𝒴₀ 为基类；n_c 为类 c 的样本数。

### 4.1 参考分类器（BiMC / BiMC†）
- 文本：t̃_c = (1−λ_T) t_c + λ_T d_c。
- 视觉：v_c 为单位化的类均值。新类做整体收缩：v_c ← n((1−λ) v_c + λ·n(Σ_b w_b v_b))。
- 融合：μ_c = n(β t̃_c + (1−β) v_c)，p_ref = softmax(f·μ)。BiMC† 再加上基类协方差项和新类描述近邻项。

### 4.2 Shot-aware GDA 锚点（对应 B1、B2）
- **协方差。** W 为 base 训练图的池化类内协方差，用 Ledoit–Wolf 解析式收缩到 (tr W/d) I，得到 P = W_δ⁻¹。增量会话**不再更新** P，新类只追加均值，每个新类开销为 O(d)。
- **去偏（debias）。** 由 E‖x−μ̂_c‖²_P = ‖x−μ_c‖²_P + tr(PW)/n_c，得到
  s_c = μ̂_cᵀPx − ½μ̂_cᵀPμ̂_c + κ·tr(PW)/(2n_c)。
- **后验预测（predictive，更有原理，建议作为正文主形式）。** 均值取平坦先验时，预测分布为 N(μ̂_c, (1+1/n_c)Σ)，于是
  s_c = −½‖x−μ̂_c‖²_P/(1+κ/n_c) − (d/2)·log(1+κ/n_c)。
  κ=1 即标准贝叶斯预测，κ=0 退化为 LDA。
- **融合。** p = (1−ω)·p_ref + ω·softmax(s/(dT))。ω、T、κ 只在 base 伪增量上选。
- **可写进论文的分析点。** 可以给出 κ 修正后基类 / 新类误判率的变化方向。另外，"冻结 base 协方差 + 只追加均值"等价于在 base 空间做白化后的最近类均值，这能解释它为什么不遗忘。

### 4.3 分解–重组（对应 B3，FDR 结构）
- **整体步。** 供体权重改为文本相似度：w = softmax(τ cos(t̃_n, t̃_b))。这是 FDR 代码里实际执行、论文里没写的一步，K0 单独检验它。
- **分段步。** 对每个分段掩码 g，在掩码维上取文本相似度 top-r 的基类，按 FDR 式 (8)(9) 依次更新 p_n[g]。
- **关键词分段。** 关键词由 BiMC 描述自动抽取（不需要 LLM），只由当前协议的 base 类定义词库。grounding 在**最终 CLIP 坐标**中计算，修正了 FDR 代码的坐标不一致。K1_fdrcoord 对照原始坐标。

### 4.4 频率作为视觉分解轴（叙事 A 的核心；叙事 B 中作为对照）
- **视觉频率 grounding。** 用 Gaussian 梯度 σ₀=0<σ₁<σ₂<σ₃ 定义 Δ_k(x) = n(f(G_{σ_{k−1}}x)) − n(f(G_{σ_k}x))。类 c 在频段 k 的掩码为 top-q(|mean Δ_k − 基类公共方向|)。新类用自己的 shot 计算掩码，所有视图都是自然模糊图，不会出现 OOD 的高通图。
- **频带信息块（F 系列）。** 取 ViT 中间层 14×14 patch-token 网格的 DCT 径向频带 RMS 能量，依次做 PCA、对 CLS 岭回归残差化、尺度对齐，再进入联合 GDA。R1 再加频带经验贝叶斯重组。

### 4.5 算法与复杂度
- **零训练。** 全流程不做任何梯度更新。
- **base 阶段。** 一次 d×d 求逆。
- **每个新类。** O(d·K) 计算均值，O(|𝒴₀|·d) 做重组。
- **测试。** 每个查询的计算量与 BiMC† 同量级。频率视图只在 support 上需要（Q 系列）；F 系列在查询上需要一次额外的中间层读取（同一次前向）。

## 5. 贡献点草案

**叙事 B**
1. 指出免训练 CLIP-FSCIL 中协方差错配与 shot 相关打分偏差两个被忽视的问题，并给出闭式的 shot-aware 判别器：base 冻结的类内协方差加后验预测修正，附带理论分析。
2. 在统一的分解–重组框架下重新审视 FDR，分离出文本供体权重与关键词分段两个因素，修正 grounding 坐标，并给出它们在 5-shot 与 1-shot 下的作用边界。
3. 在三个基准、5-shot 与 1-shot、两种骨干上系统验证，并用严格对照给出"频率作为属性"的负结论及成因分析。

**叙事 A**：第 3 条换成"提出视觉频率 grounding 的分解–重组，在类特异、shot 稳定的通道子集上迁移基类知识，并以随机 / 换类 / 增强对照证明增益来自频率排序本身"。

## 6. 实验设计

### 6.1 设定
- **数据集。** CIFAR-100（60 + 8×5，5-shot）、miniImageNet（60 + 8×5）、CUB-200（100 + 10×10），以及 CUB 1-shot（FDR 的协议）。
- **support。** 5 个 seed（1–5），与 engine 的采样器逐位一致，抽取时会自动核对。如能整理出 CEC/TOPIC 的标准划分 manifest，用 `--standard-manifest` 存为 seed 0 并单独报告，便于和文献数字直接对比。
- **骨干。** 主实验用 ViT-B/16；泛化实验用 ViT-L/14（可选 ViT-B/32）。
- **可选扩展。** ImageNet 子集或另一个细粒度数据集（如 FGVC-Aircraft），需要新写数据加载器，不作为首投的必需项。

### 6.2 指标与统计
- **基本指标。** 逐 session 精度、Avg、Last、PD，以及最后一个 session 的 Base / Novel / HM。CUB 另报 FDR 式 NAcc。
- **统计。** 5 个 seed 报 mean±std。与 anchor 和 BiMC† 做配对比较：bootstrap 95% CI（seed 内对图像重采样）、为正的 seed 数、fixed / broken 计数、每个 seed 的 McNemar 检验。
- **结论门槛。** 一个提升只有满足 CI 不含 0 且至少 4/5 个 seed 为正，才在正文中称为"提升"。

### 6.3 对比方法
- **免训练，在同一缓存上复现。** ZS、Proto、TEEN、BiMC、BiMC†、FDR-TF（发表超参）、LA（常数 logit 调整）。
- **需要补实现。**
  - ULA（CVPR 2026 Findings）：原文 PDF 这次没能读到，请下载后按原文实现；它是 logit 层面的插件，可以叠加在 BiMC† 和本方法之上。
  - HyCal（2026）：按 Mahalanobis–cosine 随样本数加权的形式实现，作为 shot-aware 的另一种做法对照。
  - FeCAM：数字引用 BiMC 论文。
- **训练类方法（单独分组，只引用原文数字）。** CEC、FACT、CPE-CLIP、PriViLege、LP-DiF、FDR（LoRA）、SGLC（CVPR 2026）等，在表中标明 Training-free = No。

### 6.5 协议红线（写进论文 Implementation Details）
- 所有超参只在 base 伪增量 episode 上选：A/V 对半划分，3 个划分 seed × 10 个序列；support 与 query 不相交。
- 选参约束：base / novel 精度都不低于 fallback 0.2pp 以上。
- 测试集只评测锁定配置，`evaluate` 会校验 hash 和 bank。
- 最终方法由哪些组件构成，在跑测试集之前依据 `gates.txt` 决定；决定后不得再根据测试结果增删组件。
- BiMC 的 β 在原文中同样是在 base 内部的验证划分上选出的，可以引用这一点说明本文协议与之一致。

### 6.6 计算预算
- **特征抽取。** 每个数据集一次。CUB 约 1.2 万张图 × 6 个视图，加 3 层 DCT，单卡约几分钟到十几分钟。mini 和 CIFAR 视图更多、图更多，DCT 默认只取第 9 层。
- **选参。** 整个矩阵在 CPU 上每个数据集、每个 shot 约 1 小时以内（按 2 核粗估，你的机器应该更快）。
- **评测。** 每个 entry × 5 个 seed 约几分钟。

## 9. 写作提纲（Neurocomputing 常见篇幅，双栏约 10–14 页）

1. Introduction：三种偏差，配一张"新类被系统性打压 / 抬高"的示意图；列出贡献。
2. Related work：FSCIL（训练类 / 免训练）、CLIP 免训练适配（Tip-Adapter、GDA、ProKeR）、原型校准（TEEN、FDR）、频率视角（只在叙事 A 中展开）。
3. Preliminaries：协议，BiMC 回顾。
4. Method：4.1–4.4，配算法框和复杂度。
5. Experiments：设定、主表、消融、频率研究、敏感性、骨干、开销。

### 12.6 关键转折：频率通道 ≈ 高类内方差通道（2026-11-03）
- **同样大小的通道集合，类内方差最大的通道（Q6_var）不输于频率通道（Q6_union）。**
  - 1-shot：75.92 vs 75.38；5-shot：81.02 vs 80.96。
  - 激活幅值通道（Q6_mag）基本持平；Fisher 通道（Q6_fisher）和随机通道明显更差。
  - errconc 中误差集中度：类内方差 ×1.78 > 基类频率通道 ×1.61 > 幅值 ×1.57 ≫ Fisher ×0.89 ≈ 关键词 ×0.88 ≈ 随机 ×0.99。
- **解释。** K-shot 均值在通道 j 上的期望平方误差为 σ_j²/K，误差天然集中在类内方差大的通道上。模糊梯度掩码之所以有效，是因为模糊引起的特征变化正好落在这些高方差的"实例细节"通道上，频率只是方差的代理。FDR 的语义关键词通道恰好避开了这些通道（×0.88），这能解释为什么它在 5-shot 下几乎无效。
- **方法据此改为有原理的闭式版本 Q7_eb：逐通道的经验贝叶斯重组。**
  - 公式：ρ_j = λ · s_j²/(s_j² + t_j²)，s_j² = σ_j²/(K g²)，t_j² 为供体估计在基类上留一估计出的误差方差。
  - 它统一并推广了 K0（ρ 取常数）和 Q6_var（ρ 取 0/1 的硬掩码），而且 K 直接出现在 ρ 里，天然随 shot 数变化，不需要按 shot 调强度。
  - 匹配对照：Q7_uniform（ρ 取每类均值，等价于整体收缩）、Q7_shuffled（ρ 在通道间打乱）、Q7_eb_visual（供体权重改用视觉相似度）。
- **论文改走叙事 B 的强化版：shot-aware 统计校准。**
  - 判别端：base 冻结的类内协方差 GDA 锚点。
  - 原型端：逐通道 EB 重组。
  - 分析端：频率、FDR 关键词、方差三者统一在"原型误差集中度"这一框架下解释。
  - 频率在这一框架下作为"被方差解释掉的代理变量"，属于一条完整的负结论加机制解释。
- **ULA。**
  - 官方默认超参在 CLIP / BiMC† 上明显有害：1-shot −3.8，5-shot −12.3。
  - 重新选参后，1-shot 只有 +0.46，5-shot 选不出优于不加的配置。
  - 叠加在本文方法上也没有增益。
  - 这一点如实报告。选参中 include_fallback 已修正：组合实验中如果插件不带来增益，就保留不加插件的版本。

### 12.7 Q7_eb 未过闸门；方法改为独立的方差引导分段重组（2026-11-03，结果出来之前预先登记）
- **CUB 开发集结果（Last / HM，3 个划分方向）。**
  - 1-shot：BiMC† 71.76 → K0 73.73 → Q6_var 75.92；Q7_eb 74.53，Q7_uniform 74.42，Q7_shuffled 74.41。
  - 5-shot：BiMC† 78.84 → A2 80.33 → K0 80.44 → Q6_var 81.02；Q7_eb 80.53，Q7_uniform 80.43，Q7_shuffled 80.43。
  - Q7_eb 比 Q6_var 低 1.39 / 0.49，比 uniform / shuffled 只高约 0.1：软的逐通道权重几乎不起作用。
  - Q7_eb 选出的 λ 在 1-shot 为 0.5、5-shot 为 1.0，与 EB 预期的随 K 变化方向相反，说明它对 K 的依赖本身就估错了。
  - Q7_eb 的新类精度明显偏低（1-shot N 69.56，Q6_var 为 75.79）：新类原型修正得不够。
  - ULA 叠加在 Q7 上两个 shot 都退回不加 ULA 的版本。
- **诊断（是假设，由本轮消融检验）。**
  1. 解析式 s_j² = σ_j²/(K g²) 估错了归一化后 K-shot 原型的误差。1-shot 时 ‖x‖² ≈ ‖μ‖² + tr Σ，归一化用的是 ‖x‖ 而不是 ‖μ‖，于是 ρ 在几乎所有通道上都饱和到 λ，退化成整体收缩。
  2. Q6_var 有两样 Q7 没有的东西：它叠在 K0 的整体收缩之上；供体按"所选通道内"的相似度排序（FDR 的分段思想），而 Q7 对全部通道只用一个全局供体。
- **方法改为 M1：独立的方差引导分段重组。**
  - 只用基类数据，按合并类内方差取 top-k 通道，作为所有新类共用的一个通道集合，再用"该通道内相似"的基类原型重组。
  - k 是独立超参，取维度的比例，不再借用频率掩码并集的大小。k 取相同值时，M1 与 Q6_var 完全等价（有测试）。
  - 匹配预算对照沿用 M1 的 k，并对每个对照重新选 α（对对照更公平）：
    - lowvar：方差最低的 k 个，检验方向；
    - random：3 次随机抽取取最好的一次，偏保守；
    - fisher、mag、freq（基类平均的模糊敏感度）、ebratio（σ²/t²）。
  - 组件消融（各自重新选参）：去掉整体收缩（M1_noholistic）；供体改按全向量相似度排序（M1_global）；供体相似度改用视觉原型（M1_visualsim）。
  - **M2_ebmask：随 shot 自适应的 EB 判据。**
    - 规则：当且仅当实测的 K-shot 误差 s_j²(K) > c·t_j² 时借用通道 j。
    - s_j²(K) 直接在基类上通过抽 K 张图测得，不做近似。
    - 没有 k；K 增大时通道数自动减少。c=1 是理论点。
  - **Q7e_eb**：软 EB 改用实测 s²，检验诊断 1。
- **预先登记的决策规则（看到结果之前写下）。**
  1. G3 在 1-shot 通过（M1 − K0 ≥ +0.3，且比 random / lowvar / fisher 都高 ≥ +0.2），且 5-shot 下 M1 ≥ K0，原型端就定为 M1；否则原型端保持 K0，方差分析只作诊断。
  2. 两个 shot 都满足 M2 ≥ M1 − 0.1 时，改用 M2（少一个超参，并且随 shot 自适应）。
  3. 组件只有在两个 shot 下去掉都损失 ≥ 0.1 才保留并写进论文；否则换用更简单的版本。例如 global ≈ segment 就用 global，去掉整体收缩不掉点就去掉。
  4. Q7 / Q7e 作为"软加权 vs 硬选择"的消融报告。
  5. 5-shot 下 var、mag、freq 不分胜负是预期之内的（三者高度重叠，errconc v2 会给出 Jaccard 重叠度）。论文中的主张以 1-shot 和误差集中度曲线为准，不宣称 5-shot 下方差严格优于幅值。
- **errconc v2**：新增低方差掩码；var / mag / fisher / freq 同尺寸掩码之间的 Jaccard 重叠度；捕获率–通道预算曲线（含 oracle 上界，即各类自己误差最大的通道，不可用，只作为上界）。这条曲线将作为论文的 Figure。

- **预先登记（看到 M3 结果之前写下）。**

- **论文叙事（暂定）。** 题目方向是 "Replace where it is noisy: variance-guided prototype recomposition for training-free FSCIL"。
  - 现象：K-shot 原型误差集中在少数与类别无关的高类内方差通道上。
  - 方法：只替换这些通道。
  - 解释：频率掩码有效，是因为它们是方差的代理（与方差的重叠为 0.30，误差捕获率排第二）；FDR 关键词通道和 Fisher 通道恰好避开了误差（×0.88 / ×0.89）；软收缩会伤到准确的通道。

### 12.9 M3 通过；按规则定下最终方法 M4，并修正两处会影响测试的实现问题（2026-11-03 中午）
- **CUB 开发集结果。**

    - 相对 A2 的 71.76 高 6.07（HM 高 8.08），3 个划分方向全部为正。
    - 比 random 高 1.46，比 lowvar 高 5.04，比 fisher 高 4.04，比 mag 高 0.77，比 freq 高 0.54，比 M1 高 1.90。

## 13. 改投 Neurocomputing 的修改计划（2026-11-09）

依据：模拟审稿意见（main_v6，Major Revision）、BiMC 补充材料、FDR / ULA 原文，以及 Neurocomputing 与 Elsevier 的现行要求。前提：不再必须使用频率；目标期刊由 TAI 改为 Neurocomputing。

### 13.1 总体判断
- 审稿意见里与 TAI 格式有关的条目，改投后不再适用：运行标题、10 页超长费、Impact Statement、IEEE 模板。
- 决定能否被接收的是四件事：
  1. 叙事说过头（Major 1）；
  2. 缺少只用 σ̄² 的软收缩基线（Major 2）；
  3. 新颖性定位不足（Major 3）；
  4. 只有一个 backbone（Major 4）。
- 另外三件影响可信度：5-shot 收益归属（Major 5）、置信区间低估不确定性（Major 6）、"pre-registered" 无法核查（Major 7）。
- 不再必须使用频率后的处理：
  - 频率从标题、摘要、引言和方法中全部移除，只在补充材料里保留一段"与 FDR 频率 / 关键词分解的关系"。
  - 这同时解决了"标题以 Frequency 开头，但方法不用频率"的问题。
  - 与 blur 相关的行（Table I 的 blur 三行、Table IX、Sec. IV-D）移到补充材料或删去。
  - FDR 关键词分段保留：它是主要的对比方法。
- Neurocomputing 的硬性约束：
  - 常规论文必须与神经网络 / 学习系统直接相关，明确不收"现有算法的单纯组合"。所以主贡献必须是 DCR 和对误差的分析，GDA anchor 只能作为已有的可选组件。
  - 单盲审，无硬性篇幅限制。
  - 投稿材料以 13.7 为准（已对照 Guide for Authors 原文核对）。

### 13.2 新版定位与叙事
- 题目候选：
  - "Variance-Guided Detail-Channel Recomposition for Training-Free Few-Shot Class-Incremental Learning"
  - "Where Few-Shot Prototypes Go Wrong: Variance-Guided Channel Recomposition for Training-Free Few-Shot Class-Incremental Learning"
- 三条贡献（措辞收窄）：
  1. **诊断。** 冻结 CLIP 特征上，K-shot 原型的误差不成比例地落在 pooled within-class variance 高的通道（集中度为随机通道的 1.7–2.3 倍）。这个排序由基类数据一次算出，新增"基类与新类方差排序的秩相关"作为直接证据。一阶模型定位为"解释"；只有 E9 给出数值预测后，才写"预测"。
  2. **方法。** DCR 在这些通道上，用相似基类原型构成的 donor 替换 K-shot 值。它闭式、免训练，可以插入 BiMC、BiMC† 和原型分类器。
  3. **评估。** 只用基类数据选参，测试集只评估一次。误差类型分析说明替换何时优于整体收缩：新类之间互相混淆为主时（CUB），而不是新类被判成基类为主时（CIFAR）。
- 主结果行改为"BiMC† + DCR"（E4）；"+ GDA anchor"作为单独一行，并注明它来自 Wang et al. (ICLR 2024) 和 FeCAM 一类协方差方法。
  - 这样 Major 5 的贡献归属问题自然解决，也避开"现有算法组合"的问题。
  - 1-shot 时 anchor 本来就被选为关闭，主结论不受影响。
- 1-shot 设定有先例：FDR (ICCV 2025) 用了 CUB200-1-shot（10-way 1-shot）。正文以标准 5-shot 为主，与已发表数字比较；1-shot 作为低样本设定一起报告。

### 13.5 新实验清单（规则在运行前写下；除 E6 外都只需 CPU，跑在已缓存的特征上）
- **E1 只用 σ̄² 的软收缩**
  - 设定：m_j = σ̄_j² / (σ̄_j² + C)，C ∈ {0.25, 0.5, 1, 2, 4, 8} × median(σ̄²)；donor 与 DCR 相同（全局排序，r、τ 网格相同）；强度 α ∈ {0.7, 1}；chain 到 A2。
  - 流程：6 个设定先在开发集上选参，再测试一次。
  - 规则：
    - 若软收缩在 6 个设定中至少 4 个的测试 Last 不低于 DCR，或所有设定的区间都覆盖 0：正文改写为"DCR 是 σ̄² 收缩的硬阈值近似，两者精度相当，保留硬版本是因为只需一次排序"。
    - 否则：只在测试区间 > 0 的设定上写"硬替换更好"。
    - 无论哪种结果，方法都不变。
- **E2 APE 式通道对照**
  - 设定：用 APE 的准则（类间相似度与类间方差的加权）在基类原型上给通道排序。两个对照：替换 APE 认为最重要的通道（APE-top），以及最不重要的通道（APE-bottom）。预算与 DCR 相同，α 重新选。
  - 规则：只作为对照报告，进入 Fig. 3 和 Table III。
- **E3 小预算测试点（1-shot，三个数据集）**
  - 设定：k 固定为 0.1 和 0.2，r、τ、α 在开发集上重选，然后测试一次。
  - 规则：在正文中标为事后分析（post hoc）；与"选中预算下的误差捕获比例"一起报告。
- **E4 不带 anchor 的 BiMC† + DCR**
  - 设定：chain 到 BiMC_ens，网格与 M4a 相同；开发集选参，然后测试。
  - 规则：作为主表里的"ours"行；M4a 作为"+ GDA anchor"行。1-shot 时它应与 M4a 完全一致，跑完核对。
- **E5 shot 扫描，K ∈ {1, 2, 3, 5, 10}**

- **E6 ViT-L/14（需要 GPU 提特征）**

    - 我们的方法与对照：E4、M4a、random、lowvar、fisher、shrink-all、E1。

  - 规则：沿用冻结的网格和规则，不针对新骨干重新设计。

### 13.10 稿件中要改正的事实问题（本轮核对代码时发现）
1. **donor 公式。** 代码（recompose.segment_step / weighted_step）里，donor 是 top-r 个单位基类原型的 softmax 加权平均，本身不再归一化；只有重组后的整个向量做归一化：q_c = Σ_{b∈𝒩_r(c)} w_cb μ̄_b，p̃_c = n(p̂_c + α m ⊙ (q_c − p̂_c))。稿件 donor 公式里的 n(·) 要删掉。BiMC 的整体校准（recompose.holistic）才对 donor 归一化，两处要分开写。
