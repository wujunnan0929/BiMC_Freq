# 下一步：多层视觉证据与多属性原型补全

日期：2026-10-27。本文为文献核查与下一轮实验设计，不是新增实验结果。本轮不修改模型实现、不启动正式测试。

## 1. 决策与已有证据

建议保留原型补全主线，将频率作为可选择的一种视觉证据，研究问题改为：**少量支持图像中的哪些类别属性估计不可靠，哪些层或局部表示能提供有效补充，以及这些补充能否改善完整 FSCIL 判别。**

已有 CUB 三支持种子结果：原图单视图补全相对 BiMC Final +0.4257pp；repeat +0.5005pp；输入低通频率版 +0.2704pp。频率版三个种子都低于原图单视图。原图单视图的 Base +0.1164pp、Novel +0.7281pp，说明一般补全仍有正向信号。完整来源见 `outputs/tmp/completion_analysis_20261027.md`。

当前 repeat 同时改变第二份文本、联合子空间和收缩几何，不能把收益直接归为重复视觉信息。当前 structured 文本只是“emphasizing shape/parts/texture”等模板，主要的类别信息仍来自类别名；尚未检验明确的类别属性事实，如具体喙形、胸部颜色及翼部图案。

## 2. 三条轴分别检验

| 轴 | 首轮范围 | 解释边界 |
|---|---|---|
| 层深 | ViT-B/16 block 3、6、9、12 | 表示保留和抽象程度，不直接命名低中高频 |
| 空间频率 | 输入图像频率，或选中层的 patch 网格频率 | 必须明确变换所作用的空间坐标 |
| 语义属性 | 整体比例、部件形态、颜色分布、斑纹纹理 | 不与某一层或频带预设一一对应 |

中间层或局部特征有效，不自动证明频率有效。多属性描述有效，也不自动证明属性分组或补全机制有效。

## 4. 先解决 repeat 的混杂：零新增图像编码

复用当前原图缓存，只在原始基类开发集完成以下五项：

| ID | 配置 | 目的 |
|---|---|---|
| R0 | 单视觉观测，普通文本先验，rank 16 | 当前简洁参考 |
| R1 | 同上，rank 32 | 子空间容量控制 |
| R2 | 复制视觉，复制同一文本先验 | 重复表示和正则化控制 |
| R3 | 复制视觉，加入第二份属性文本 | 对照当前 repeat，隔离额外文本 |
| R4 | 只有一份视觉观测，融合与 R3 相同的两份文本 | 检查是否需要复制视觉观测 |

补充报告两种 rank 预算：单块 32 对双块 16+16；单块 16 对双块 8+8。rank 只是容量近似，另报联合有效秩、实际统计标量和原图子空间。

重复同一视觉不能使 K-shot 变为 2K-shot。理想对照应在公共基底及对重复表示一致的正则化下，重复观测退化回单观测。现有全矩阵 isotropic ridge/shrinkage 不保证此性质，因此先记录 R2 与 R0 的差异，不把它归为新增信息。下一版宜先合并完全重复的观测，再拟合统计。

**继续条件：**确认 R3 的增益是否可由 R4 保留；明确额外文本与正则化各自的作用后，再将它们作为多层方案的强参考。

## 5. 多层表示：一次前向，先做纯视觉筛查

### 5.1 代码现状与提取

`models/clip/model.py` 的 `VisionTransformer.forward(all_layer_outputs=True)` 已逐层返回 CLS，但将每层都套上最终 `ln_post/proj`，且不返回 patch 网格。`CLIP.encode_image` 当前没有暴露这一开关。

下一版建议增加显式的 selected-block 输出，不改变默认 forward：

- block 3/6/9 原生 CLS：768 维；block 12 最终全局输出：512 维。
- 原生 patch tokens：去掉 CLS 后恢复 14×14×768，先仅在筛查选中的层读取。
- 默认查询端仍使用最终全局输出；支持端一次前向收集选定层，按批立即压缩或池化。
- 一次 encoder forward 不等于零成本：额外保存、池化、PCA 和评分均需计时及计峰值内存。不要默认缓存全部图像的全部层 patch tokens。

### 5.2 首轮只筛三个中间层

固定相同普通文本和统计容量，分别比较最终层＋block 3、＋block 6、＋block 9。每块采用 A-only 拟合的原生空间 PCA，最终只修正最终层原型。

中间层先不直接与文本做点积：辅助块使用基类全局均值或纯视觉联合统计作简单先验。只有中层有新增收益，才比较最终投影的启发式与 A-only 低维闭式 ridge 语言映射；不能把新映射的收益直接算为层本身的收益。

首轮目标块和辅助块的总潜变量 rank 固定，再另报每块固定 rank 的容量扩展结果。维度不同应使用异维 blocks，不为凑 512 维强行调用最终投影。

若 CLS 有信号，固定选中层，再比较 patch 均值与 patch 均值＋标准差。局部属性可能保留在 patch 分布而非中间 CLS，但这属于后续候选，不能同时遍历所有层、池化和频段后挑测试最优。

### 5.3 一个必要的表示瓶颈诊断

对同一组选中层，同时比较：

1. 支持端多层证据补全，查询只用最终层。
2. 各层原生视觉原型分类器在类别分数空间融合，查询也读取选中层；仍是一次原图前向。

若第 2 项有效而第 1 项无效，说明最终层查询表示可能限制了可利用信息，不宜继续强迫所有属性回到一个最终层中心。第 2 项是强多层分类对照，不自动成为属性补全贡献。

## 6. 多属性：先定义可观测内容，再比较补全

建议四组，每组首轮两条描述，总量为八条：

| 属性组 | CUB 示例 | 注意点 |
|---|---|---|
| 整体比例与轮廓 | 长翼、短尾、细长体形 | 使用可视比例，避免图像无法判断的厘米/体重 |
| 部件形态 | 钩状喙、圆头、分叉尾 | 与颜色分组分开，允许不可见/未知 |
| 颜色及分布 | 头冠深色、胸腹黄色、翼上白斑 | 颜色必须带区域，注意性别/季节/个体差异 |
| 图案与纹理 | 胸部条纹、羽缘、翼部斑点 | 与“细节很多”这种泛化模板区分 |

输入频率或特征频率属于证据，不必再占一个固定语义属性组。姿态、背景、光照主要作支持质量/干扰因素诊断，首轮不与物种属性一起强行补全。

优先从现有普通描述中提取明确可视内容。当前文本含栖息地、地理、行为和生命周期等句子，应过滤；不能把所有描述都当图像可观测属性。组内不足时保留 unknown/缺失掩码并报告覆盖率，避免复制同一通用句子凑数量。若以后生成新描述，冻结文本文件后才评估，并保留生成与验证成本。

同样本、同文本信息下区分四种语义处理：

- T0：八条普通可视描述，统一聚合。
- T1：八条明确属性描述，统一聚合，只检验文本内容增益。
- T2：与 T1 **完全相同的八条描述**，保留四组观测与组级可靠性，检验属性处理机制。
- T3：与 T2 **完全相同的八条描述**，预先固定一份均衡随机四组，匹配每组数量、测量维度、rank、H/Q 与门控容量。它是首轮必要控制；T2 超过统一平均但不超过 T3，只支持保留更多文本信息，不支持语义分组本身有效。进入正式结论前再用多份预注册乱分验证稳定性，不挑最差乱分作对照。

T1 与 T2 的文本顺序或分组操作必须在实现中确实影响计算；全体等权均值本来就对分组置换不变，不能用其不变性当反证。后续乱配控制只破坏语义与对应的观测/修正方向，不同时重排两侧。

第一版不根据新类支持挑选文本，再把选中的文本当独立先验。支持指导文本定位可作为单独版本，但必须显式处理同源相关性与选择偏差。

## 7. 推荐的模型组织：一份视觉观测，多组语义证据

不要为四个属性复制四遍同一视觉向量，也不假设最终 CLS 等于各层/各属性向量之和。

一种可精确实现的闭式候选，是以最终层低秩类别中心 u 为目标，将不同层和文本组看作不同类型的测量：

```text
y_c = [最终层支持均值；选中中层支持均值；形状文本；部件文本；颜色文本；图案文本]
y_c = H u_c + b + eta_c + epsilon_c
u_c ~ N(m, B)
Cov(eta_c) = Q                 # 跨类映射残差/语义不匹配，不随 shot 缩小
Cov(epsilon_c) = W / K         # 同图跨层采样噪声；文本行没有这种采样噪声

u_hat = m + B H^T solve(H B H^T + Q + W/K, y_c - H m - b)
```

- 各测量保持原生几何，在 A-only PCA 后允许不同维度；最终层观测对应的 H 块为单位阵。
- H、b 和残差统计只在 A 类拟合，可用低维闭式 ridge。Q 应由 A 内按类别交叉拟合的残差估计，避免把拟合残差接近零误当先验精确。拟合类均值也有采样噪声，须做有限样本校正或用独立教师银行估计，不能将其当真值。
- W 保留同一图片在各视觉层的相关性；文本编码不因支持从 5 张变 10 张就变得更可靠。必须保留模型的结构零：Q 的最终层行/列为零，W 的文本行/列为零。在非零子块上做 PSD/收缩，不能用全矩阵 isotropic ridge 虚构这些误差；求解器数值 ridge 作为单独近似记录。B 做 PSD/收缩，并报告有效秩。
- 全部观测是同源证据，完整交叉块与 block 对照均需保留。该高斯模型的独立噪声假设是近似，应检查类别留出残差，而非把闭式公式当有效性证明。
- 一般联合统计版本先只估计整体修正。若要主张选择性多属性补全，还需按组生成可追踪的修正、做 leave-one-group-out，并在相同最终层基底内合并，处理属性方向的相关性。

最终分类仍以固定参考原型为起点，加入受限修正，零修正严格返回参考。首先验证最终层支持端补全；表示瓶颈诊断通过后，再决定是否允许查询使用多层分类器。

这个设计包含基类数据学习，虽然没有梯度优化。它区别于当前 repeat 的重点，是明确区分“同一视觉观测”“额外文本测量”“类级先验误差”和“随 shot 变化的采样误差”，而不是引入更多并列分支。

未来实现至少验证：零修正严格等于参考；完全重复观测经合并后预测不变；无数值近似时 K 趋大输出趋向最终层支持均值；极不可靠的辅助测量能退回简单模型；文本个数增加不能伪造更多支持样本；基类拟合与验证 query 隔离。

## 8. 最小主矩阵：两种视觉 × 四种语义

先固定一个由基类开发选出的中间层；多层并非自动打开全部层。

| 视觉证据 | T0 普通文本 | T1 属性文本统一聚合 | T2 相同文本按属性处理 | T3 相同文本随机分组 |
|---|---|---|---|---|
| V0 只有最终层 | 当前强简单参考 | 文本内容作用 | 属性候选 | 同容量分组控制 |
| V1 最终层＋选中中层 | 纯多层作用 | 两类信息能否互补 | 联合候选 | 同容量联合控制 |

八项共享支持、查询、文本候选总数、最终层基底、总潜变量预算及选择规则；T2/T3 另匹配测量和统计参数容量。每个候选可按同一预注册网格选择强度；另做固定强度比较，排除不同自动强度对机制归因的混杂。

若 T1≈T2，保留更简单的文本聚合，不声称属性选择性。若 T2≈T3，不主张语义分组或属性可靠性有独立价值。若 V1≈V0，原图单层可能已经足够，先停止扩大层分支。若各层类别分数融合已经解释收益，不能把它包装成原型补全特有增益。

## 9. 有条件开展 patch 网格频率

仅在选中层的 patch 表示显示互补性后，研究该层的空间频谱。

令 X_l 为 H×W×D 的 patch 网格。FFT/DCT 沿 H,W 做；不能沿任意 768 个通道做 FFT 后称图像空间频率。

高通滤波去掉 DC 后，直接全局平均带符号特征会接近零。首轮提取每频段、每通道的 RMS/能量，或局部保留位置的池化。能量不保留相位和位置，可能只适合质量/可靠性估计，不能自动提供原型修正方向。

最低控制为：同层均值＋标准差、固定空间分区池化、真实频段能量、等系数数量的随机频率分组。统一输出维度、频段归一化和统计预算。位置编码/背景可能影响频谱，可在 A 上估计并去除公共位置均值，作为明确的独立消融。

测量“层×属性”响应，而不预设配对：颜色变化、模糊、局部遮挡等操作只作受控诊断，不能自动解释为纯因果干预。若乱分频段与真实频段相当，归纳为一般二阶统计或多层表示收益。

## 10. 属性有效性与学习版的进入条件

[CUB 官方数据](https://www.vision.caltech.edu/datasets/cub_200_2011/)提供 312 个二值属性和 15 个部件位置。可在**原始基类训练图像上**做事后诊断，检查哪些层反映颜色/部件/图案，以及遮挡与可见性的影响。首轮主方法仍只使用既有图像类标签和冻结文本；人工属性/部件标签不得悄悄进入主方法选择或参数拟合。若使用它们监督或选层，必须另列额外监督实验。

支持与文本低相似不等于属性缺失；也可能是描述错误、性别差异、不可见、背景干扰或图文错位。可靠性应检验能否预测独立 query 的间隔/净纠错，而不能只报告与自己的置信度相关。

只有 T2 和新增视觉证据均显示独立收益后，才训练一个共享小门控，输出四个属性的可信度或噪声膨胀系数；先不输出自由的 512 维残差。以独立 query 的完整分类为主，独立教师中心/间隔作辅助，纳入旧类查询以约束新旧竞争。

## 11. 协议、预算与停止条件

1. 首轮只用原始基类开发。使用三个固定类别划分种子（建议 2/3/4），与已有支持身份规则一致；每个划分先固定保留 A 查询，PCA、ridge、协方差和交叉拟合均不能读取 V 或固定 A 查询。
2. V 只用于层/属性/强度选择，不拟合映射。参数选定后再按固定规则全基类重拟合。主要候选确认时增加未参与本轮选择的外层类别折，减少反复使用同一 V 的适配。
3. 如需教师诊断，episode 的 S/T/Q 互斥。优先 S=5、T≤15、Q=5；先核实每类可用数量，不足时明确减少 T 并报告，不通过重复样本填充。教师不是严格性能上界。
4. 以配对的平均阶段整体准确率为主，Base/Novel 各下降不超过预先固定 0.2pp，H 为辅；报告改对/改错、组内/组间错误、独立教师中心误差及 query margin。重复阶段查询不当成独立实验。
5. P0 五项＋三个中层初筛＋八项主矩阵，每个类别划分 16 个基础配置，三个划分合计 48 个基类配置评估；参考和缓存可复用。这不是 48 次正式 benchmark，也不要求梯度训练。48 不是所有消融的总上界：双 rank 控制、简单多层类别分数对照和外层类别折分别预注册、计数；patch 频率和 tiny gate 暂不执行。前序没有增量价值时即停止后续阶段。
6. 仅当新增信息超过同容量单层、同文本、复制表示和简单多层分类对照，且跨划分有重复正增益，才进入正式实验。若只降低中心误差、没有完整分类净收益，停止扩大该补全器。
7. CUB 现有测试已用于探索，后续须披露这一开发历史。固定方法后再检验其他数据集与未查看的支持抽样；同一测试图像的新支持种子不是全新独立测试集。不要对所有层×所有频带×所有属性跑正式测试后挑最优。

## 12. 下一版实现范围

- 编码器：选中层的原生 CLS/可选 patch 池化输出，默认最终输出保持精确一致；一次原图前向计数。
