# 性能优先的研究路线：判别估计与专家竞争，SAFD 为辅助

日期：2026-10-25。本文是研究设计与文献核查，不是新方法的实验结果或原创性认证。

**2026-10-26 最新开发包审计：当前条件融合也未获得学习增益。** 四个 seed2 模型全部选择零步/零 blend；各自最高已评估非零 H 均低于原参考，不只是保护条件过滤。固定调权三个划分平均仅比温度校准 H +0.1165pp。暂停该模型的 40 次正式矩阵，优先做一次规模匹配及证据尺度的原因验证：训练总类数最多 50，验证全为 55–100，现有设计叠加了类别泛化和规模外推。该差异不是已证实的唯一原因；若同规模控制仍不能取得稳定收益，就停止当前分数组合主线。SAFD 已确实参与训练，但未显示可部署独立收益。详细数据见 `outputs/competitive_fusion_cub200/analysis_20261026/analysis_zh.md`。以下较早的候选方案不能据此视为已验证有效。

上述有限预算的原因验证已实现，见 [竞争证据与规模诊断](competitive_evidence_diagnostics.md)。本轮不使用辅助扰动，不修改旧正式推理路径；只在 matched 任务选择模型，再观察原规模迁移，输入标准化仅拟合 A 池。

竞争融合代码、配对控制和 Ubuntu 执行脚本现已实现，见 [竞争融合实验说明](competitive_fusion_experiments.md)。当前仅通过实现与接线验证，尚无完整数据集的新性能结论。

## 1. 决策

建议更换主创新点。暂停把 SAFD 本身、频率 prompt、频率关系引导或全局低秩度量作为论文核心。保留完整 BiMC、强原图统计分类器和校准版本作参考；SAFD 放在基类训练的支持集扰动中，作为可单独消融的辅助组件。

最值得先检验的主线是：**判别边界监督的、支持集条件化原型估计**。它根据每个新类的少量支持样本质量、文本匹配和近邻竞争关系，生成更可靠的原型；基类训练后冻结估计器，新类只需前向计算，不做增量梯度更新。

这条路线比继续做全局特征变换更贴近目前数据，但“原型补全/回归”本身不是新思想。需先证明有性能空间，再通过与普通原型回归、校准及已有方法的比较，确定哪些机制值得作为贡献。

## 2. 为什么需要转向

- 频率 guidance 的正式配对结果未显示稳定收益；频率关系与原关系高度重合。
- SAFD metric 的基类开发验证中，最好可行弱闭式候选仅 H +0.2206pp；学习版最好 H +0.0177pp，原图学习对照 +0.0143pp。
- SAFD 学习版训练 CE 从 2.5805 降至 0.9799，但训练伪新类准确率从 97.24% 降至 86.96%。这不是单纯的跨类过拟合，而是目标和评分尺度也存在问题。
- 原先 CUB 三支持种子的原图共享统计分类器 Final 约 73.404%，BiMC 约 72.472%；频率版本约 73.421%，相对强原图对照仅 +0.017pp。不能把普通统计建模的收益算作 SAFD 特异性收益。来源：`docs/frequency_discriminant_experiments.md`。

正式 G1 代表性运行的最终会话还说明，不同数据集的主要错误不同：

| 数据集 / 支持种子 | Novel 准确率 % | 新类查询→原基类 % | 在新类错误中占比 |
|---|---:|---:|---:|
| CUB / 1 | 66.4846 | 3.0375 | 9.06% |
| CIFAR-100 / 3 | 65.9750 | 22.2750 | 65.47% |
| mini-ImageNet / 3 | 91.4500 | 4.8250 | 56.43% |

来源为 `outputs/frequency_guidance_raw_20261021/outputs/frequency_guidance_{dataset}/{dataset}/G1/seed_*/metrics.json`。占比计算为 `novel_to_original_base_rate / (100 - novel_accuracy)`。这是代表性种子诊断，不是多种子的总体估计。

因此，旧新组校准对 CIFAR 可能更重要，但不足以解决 CUB 的主要问题。CUB 更值得检查新类之间的原型或表示判别力。

## 4. 主候选的具体形式

### 4.1 输入和输出

对当前到达类 c，输入仅来自允许的支持集与已见类别统计：

- 支持特征集合 `S_c`、样本数、类内离散度、leave-one-out 变化；
- 普通类别/描述文本特征，与支持集的符合程度；
- 当前已见的易混类别原型，以及本类相对它们的间隔。

用共享小型网络预测支持样本权重、文本权重及有限的原型修正。输入优先使用内积、方差、样本数等几何量，避免直接记忆类别编号。样本排列改变不应改变输出，类别重新编号也不应改变规则。

示意式为：

```text
p_ref = 原 BiMC 对该类的参考原型
delta = g_theta(S_c, text_c, uncertainty_c, seen_competitors_c)
p_hat = normalize(p_ref + rho_c * bounded(delta))
```

修正在原型空间完成，不再把任意尺度的 `16 * delta_logits` 加到混合概率的对数上。零修正必须严格复现参考方法。角度/范数限制只是控制改变量，不是准确率无退化保证。

第一版仅让竞争类别信息影响支持样本和文本的权重，不同时加入自由的高维变换、字典、图网络和多个新分支。只有简单版本有效，才考虑更多容量。

### 4.2 训练监督：不仅要求“像类中心”，更要求“能区分类别”

在拟合类 A 中分离少样本支持 S、较多样本教师集合 T 和查询 Q。教师/查询均不进入被估计的少样本支持集，Q 不参与教师原型计算。

CUB 每类约 30 张，若继续保留 5 张固定 A 验证查询，A 拟合池每类 25 张，则可用 `S=5、T=15、Q=5`。不能同时声称保留这些查询，又在拟合池使用 5+20+5 张。最终全基类重拟合在选择结束后进行，仍保持训练 episode 内集合分离。

推荐监督：

```text
L_center = 1 - cosine(p_hat, p_teacher)
L_margin = Huber(estimated_pairwise_margin - teacher_pairwise_margin)
L_total = L_margin + lambda_center * L_center + lambda_anchor * L_anchor
```

其中 margin 由独立 Q 上的正确类与难负类比较得到。教师和学生采用同一明确的分数定义；不依靠整体提高置信度降低 CE。`L_anchor` 约束不必要的原型移动。所有权重只在基类开发验证选择。

训练覆盖不同 shot、旧新类比例及难负类；受 A 类数限制，不能声称完整模拟真实 100+100 类。验证类别 V 不拟合网络或统计映射。网络仅基类训练；增量阶段冻结，只生成当前类原型并保存统计，不保留旧图或做旧样本重放。

### 4.3 候选贡献的边界

候选贡献应落在：**学习少样本支持的估计误差如何影响未见类别之间的边界，并将修复规律以冻结、类别无关的估计器迁移过去。**

不是“MLP 是新结构”，也不是“第一次做原型补全”。必须比较中心回归、不看竞争类、只看不确定性、仅校准分数等对照。如果普通回归得到相同收益，就删除复杂模块，重新收缩贡献表述。

## 5. SAFD 的最小辅助角色

仅在一部分基类训练 episode 中，对一个支持样本使用现有 SAFD 粗/中尺度缓存视图，形成支持质量扰动；其他支持、教师和查询保持原图。估计器学习在支持证据不完整时如何修复原型，而不强迫所有尺度特征相同。

正式增量推理只需原图特征，不增加 SAFD 查询分支。SAFD 是一个训练辅助组件，不承担核心创新叙述。必须比较无辅助、同预算普通增强、FFT 辅助；如只有普通增强也同样有效，应如实报告，不能把通用增强收益专门归因于 SAFD。

## 6. 性能优先的最小实验顺序

| 顺序 | 实验 | 回答的问题 | 决策 |
|---|---|---|---|
| P0 | 分支温度、描述数量控制、旧新组偏置 | 目前有多少收益只是分数校准？ | 建立强参考，不能将校准本身当主要新意 |
| P1 | 少样本原型 vs 独立较多样本教师原型 | 新类中心估计是否有明显性能空间？ | 若差别很小，停止原型修复路线 |
| P2 | prototype / covariance / description 专家的诊断 oracle | 各证据是否有真实互补？ | 若互补小，复杂融合器缺少信息来源 |
| P3 | 普通原型回归 vs 边界监督条件估计器 | 主机制是否超过简单学习基线？ | 只有可重复超过才保留 |
| P4 | +普通增强 / +FFT / +SAFD | 辅助扰动是否有独立作用？ | 此时再决定 SAFD 放置位置与贡献大小 |

P1/P2 的 oracle 使用了额外标注或逐查询真值，仅用于基类诊断，不是可部署方法，也不是严格数学性能上界，不能列为正式方法结果。所有诊断先在基类完成，不看真实增量测试标签来选择方案。

seed=1 的已有结果属于开发诊断。下一轮固定候选，在未参与本轮调参的 A/V 划分种子 2/3/4 上确认。它们仍共享原始数据，不能当成独立数据集；正式性能还需支持集多种子测试。

可预先设内部止损规则：相对强校准对照，若 Novel/H 只能反复获得约 0.02pp 的变化，停止增加模块；若可重复达到约 0.5pp 以上且旧类代价受控，再投入完整矩阵。0.5pp 是计算资源分配目标，不是保证、显著性阈值或期刊录用标准。

## 7. 如果原型估计没有足够空间

转向更强的表示信息：从冻结 ViT 的 patch tokens 构造针对易混类别的部件匹配，或仅在基类训练轻量视觉适配器。此时关注新类之间的细粒度差异，保留原全局分支作锚点。

该备选需要额外特征缓存及更严格的文献比较，尤其 SGLC、QR-Prompt、LDC；“增加局部分支”本身不新。若使用更大骨干或额外预训练模型，必须单列资源控制，不能把骨干升级的收益全部算作方法贡献。

## 8. 当前建议的论文主线

先用实验证明：**增量新类的低质量支持估计会造成可修复的判别边界误差；一个基类训练、增量冻结的条件化估计器能改善这种误差。** SAFD 仅作为支持质量扰动的一种实现。

当前证据不足以承诺性能提升或投稿成功。优先做 P0–P2，从性能空间决定主方法，而不是先写一个模块齐全的框架再寻找正向结果。
